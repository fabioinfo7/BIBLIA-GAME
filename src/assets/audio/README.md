# Áudio do jogo

O motor aceita arquivos locais nesta pasta. Os sons reais atualmente usados como fallback remoto são publicados no Wikimedia Commons e têm suas licenças descritas nas páginas de origem.

Para uma versão 100% offline/sem dependência externa, baixe versões licenciadas dos sons e coloque-as aqui com estes nomes:

- `elefante.ogg`
- `leao.ogg`
- `ovelha.ogg`
- `macaco.ogg`
- `zebra.ogg`

Depois, substitua as URLs remotas em `src/lib/audio.ts` por imports desses arquivos.
